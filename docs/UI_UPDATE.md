# UI 업데이트

여행 질문을 빠르게 시작하고, 현지 가이드는 참여할 수 있는 질문부터 확인하도록
화면의 우선순위를 다듬었습니다. Apple 제품에서 익숙한 여백·명확한 글자 계층·
절제된 색 사용을 참고한 Malaga 고유 화면입니다.

## 바뀐 화면

- 로그인: 여행 서비스의 목적을 짧게 소개하고, 계정 입력을 흰색 영역으로 묶었습니다.
  작은 화면은 세로, 넓은 화면은 소개와 입력을 나란히 배치합니다. 비밀번호 표시와
  키보드 제출을 지원하며 기억한 로그인 재확인/가입/테스트 계정을 유지합니다.
- 지도: 검색·역할 이동·질문하기를 알아보기 쉽게 배치했습니다. 질문하기는 GPS나
  지도 타일 로딩을 기다리지 않습니다. 질문 목록은 키보드로도 펼치고 접을 수 있습니다.
- 질문: 제목과 상황을 먼저 적고 도시·보상을 확인합니다. 예시는 필요할 때 펼칩니다.
  임시 저장, 전송 상태, 실패와 재시도 안내를 각각 읽기 쉬운 영역으로 구분합니다.
- 가이드: 수락 가능한 지역 질문을 먼저 보여주고, 실제 채택 기록·받은/대기 가상
  포인트는 간결하게 묶습니다. 프로필과 빈 화면·로딩·오류도 같은 언어로 정리합니다.
- 공통: 한 가지 파란 행동색, 흰색·중성 배경, 읽기 쉬운 글자 계층, 둥근 표면과
  넉넉한 누름 영역을 사용합니다. 답변·상세 화면의 최대 폭도 읽기 좋게 제한합니다.

## 동작의 범위

자가 호스팅 Node/PostgreSQL 구조, 질문·답변·채택·가상 보상 규칙, 계정 권한,
불확실한 전송의 같은 요청 재시도, 개인별 초안 저장 동작은 유지합니다.
화면 상태 이름만 한국어로 읽기 쉽게 표시하며 서버 상태 값은 바꾸지 않습니다.

개인 프리뷰는 계속 브라우저별 합성 데이터입니다. 실제 개인정보·현금 결제·
다른 기기 간 교환을 지원하는 서버로 소개하지 않습니다.

## 검증 기록

2026-10-02 UTC 현재 소스 기준:

- Flutter 정적 분석: 문제 없음
- 전체 Flutter 테스트: 244개 통과
- 최종 운영용 웹 빌드 성공: 개발 로그인·데모·QA 자동 로그인 비활성화
- 작은 화면·확대 글자·키보드·GPS 없이 질문하기·초안 재시도·계정 복구를 포함
- 브라우저 데모의 API/장애 테스트 12개, 시작 검사 37개, 패키징 검사 12개 통과
- 운영 API·권한·SQL·의존성 잠금 파일에는 변경 없음. 이전 PostgreSQL 통합 검사
  기록은 [VERIFICATION](VERIFICATION.md)에 있으며 이번 UI 작업에서 새로 실행한
  DB 검사로 표현하지 않습니다.

운영용 웹 빌드와 프리뷰 빌드를 분리합니다. 최종 프리뷰에는 자동 테스트 로그인을
켜지 않습니다. 호스팅 화면 캡처와 로컬 Flutter 렌더는 구분해 기록합니다.


## 화면 확인 범위

390×844 모바일, 1200×750 데스크톱, 모바일 150% 글자 크기에서 실제 Flutter
위젯을 렌더하고 PNG를 확인했습니다. 합성 계정·질문·가상 포인트를 사용했으며
폰트는 테스트 엔진의 Ahem 대신 설치된 Noto Sans CJK KR로 명시적으로 불러왔습니다.
지도 캡처는 네트워크가 없는 테스트 타일 영역을 비워 두었으므로 실제 지도 타일
로드를 검증한 이미지가 아닙니다. 새 이미지의 출처는 로컬 Flutter 렌더입니다.

같은 비공개 사이트에 정상 로그인 빌드를 배포했습니다. 이번 클라우드 브라우저는
ChatGPT 새 로그인을 요구해 로그인 경계에서 멈췄습니다. 호스팅 도구도 이번
버전의 캡처를 제공하지 않았습니다. 따라서 배포 성공, 로컬 렌더·상호작용 검사,
호스팅 브라우저 검증을 구분합니다. 이전 버전은 롤백용으로 보존했습니다.
